# Icons

Gold coin app icons, each struck with one glyph: clock, deck, house, send. They are the apps on the card table's phone; `coin-send` also marks the daily run (`.r3t-run-coin`). Full-colour raster on a transparent ground, shown as discs (`radius-round`) at 40px or larger. Never recolour, and never use one as a small inline control icon - controls use text glyphs.
